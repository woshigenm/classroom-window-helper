# 使用手册（bypass_tool）

> 本工具只解决本机全屏广播问题：把广播变成可拖动小窗、解锁键盘、解除黑屏。

> 目录结构、交付文件校验值和编译方法见 [`../README.md`](../README.md)。

---

## 1. 部署 `bypass_tool`

1. 把整个 `bypass_tool` 文件夹放到**本机磁盘**（例如 `C:\bypass_tool\`）。
   > ⚠ 不要放在 VMware 共享目录。HGFS 不支持 image section 映射，`LoadLibraryW` 会失败。
2. 给这个文件夹加 **Defender 排除项**（DLL 含 IAT patch / 注入代码，容易被判 HackTool 直接删）。
3. 右键 `bin\bypass.exe` → **以管理员身份运行**。
4. 托盘出现图标，主窗口启动时直接显示；点 `×` 后才收进托盘，
   **左键单击托盘图标**（或 `Ctrl+Alt+H`）就重新打开。

**三个运行文件都在 `bin\`，必须同目录**：`bypass.exe`、`bypass_hook32.dll`、`inject32.exe`。
DLL 会按自己的位置去找开关文件和写日志。

## 2. 日常怎么用

> **默认就是「持续保持小窗」开启状态**（不用再点按钮）：程序启动后会自动注入 DLL、
> 装窗口事件钩子，广播一来就是小窗。
>
> 想**正常看全屏广播**：把「持续保持小窗」关掉（按钮/`Ctrl+Alt+T`/托盘）。
> 关闭时会写 `bin\bypass_hook.off` 放行，**桌面看门狗同时停止工作**，不会干扰教师端的全屏。
>
> 桌面看门狗只在小窗模式开启时生效：被切到 `NetTeachingDesktop` 会 1 秒内切回 `Default`；
> 黑屏锁屏（`MCLOCK Desktop`）则连带自动解锁键盘（`0xB2008`）。
>
> **课堂软件在 bypass 之后才启动也没关系**：程序每 400ms 看一眼进程表，
> `Student.exe` 一出现就注入；它拉起 `MultiClient.exe` 时会被"挂起注入"，
> 赶在 `SwitchDesktop` 之前把钩子装好。

### 2.1 上课前

运行 `bin\bypass.exe` 就行——**「持续保持小窗」已经默认开启**，自动注入、自动监视。

只有当前已经被锁的时候才需要补点：

| 按钮 | 什么时候点 |
|---|---|
| **解锁键盘** | 键盘被锁（打字没反应） |
| **解除黑屏** | 屏幕被切成黑桌面 |

> 想**正常看全屏广播**：关掉「持续保持小窗」（`Ctrl+Alt+T` 或按钮）。
> 关闭后会写 `bin\bypass_hook.off` 放行，看门狗也同时停止，完全不干扰教师端。

### 2.2 广播来了之后

默认**窗口模式是开的**（不需要你去开）：

- 渲染器不会切到 `NetTeachingDesktop`（不会整屏黑）；
- `fullscreen` 参数被改成 0 → 广播窗口本身是 **3/4 屏的普通窗口**（有标题栏、可缩放）。

想更小、更顺手：按 `Ctrl+Alt+S`（或点「小窗化广播窗口」），窗口会缩到 1/3 宽。
之后**你自己拖大/最大化，工具不会再拉回去**——这是刻意做的。

> **键盘自动解锁**：全屏广播被降成小窗后，工具会自动补发一次键盘解锁
> （`0xB2008`，3 秒内最多一次），不需要再点「解锁键盘」。
>
> **最大化后标题栏自动隐藏**：把广播小窗最大化后，标题栏（最小化/最大化/关闭）
> 会在约 1.2 秒后自动收起，画面看起来像全屏；**鼠标移到窗口最上沿**
> （6 像素内）控制栏立刻回来，移开一会儿又自动隐藏。
> 不想要这个行为：在 `bin\bypass_config.ini` 里设 `title_autohide=0`
> （删掉即恢复，见第 4 节）。
>
> **最小化怎么收**：主界面有勾选框「广播窗最小化到任务栏」（默认勾选）。
> 勾选 = 真最小化，任务栏出现按钮，点任务栏（或缩略图、右键「还原」）恢复；
> 取消 = 收起（隐藏、不占任务栏），`Ctrl+Alt+S` 或托盘「小窗化 / 显示广播窗口」恢复。
> 为了不让渲染器把最小化顶回来，DLL 除了内联 hook `user32!ShowWindow/ShowWindowAsync`
> （日志 `inline hook installed`），还会在最小化期间：
> ① 打 `BypassTaskbarMin` 锁，拦掉应用发来的 `SC_RESTORE` **和 `SC_MAXIMIZE`**（`DefWindowProc`
> 处理它们时都**不经过** `ShowWindow` 导出，钩子看不到）；
> ② 万一还有别的路径把窗口顶出来，在 `WM_WINDOWPOSCHANGED` 里立刻压回去
> （日志 `re-minimize ...`）。
> 判断"是不是用户点的任务栏"看光标是否在任务栏/缩略图/系统菜单上且有输入，
> 窗口是否收到 `WA_CLICKACTIVE`，以及**窗口菜单是否刚被打开/关闭**（任务栏右键、
> 标题栏图标、Alt+空格）。所以任务栏右键菜单里的「还原 / 最大化」也能用。
> **两种模式都可以用 `Ctrl+Alt+S` 强制叫回来**，所以即使判断失手也不会把窗口锁死。

### 2.3 快捷键（鼠标被冻结时也能用）

| 快捷键 | 动作 |
|---|---|
| `Ctrl+Alt+H` | 显示/隐藏主窗口 |
| `Ctrl+Alt+K` | 解锁键盘 |
| `Ctrl+Alt+B` | 解除黑屏 |
| `Ctrl+Alt+S` | 小窗化广播窗口 |
| `Ctrl+Alt+T` | 持续保持小窗（开/关） |
| `Ctrl+Alt+M` | 实时解锁监控（开/关） |
| `Ctrl+Alt+D` | 立即切回桌面（被切到教学桌面时） |
| `Ctrl+Alt+E` | 应急点击（鼠标被冻结时） |
| `Ctrl+Alt+Q` | 退出 |
| `Ctrl+Alt+X` | 应急放行 |

按钮上悬停会显示对应快捷键。

### 2.4 收尾

- 平时：直接关窗口 → 收进托盘，继续后台工作。
- 完全退出：托盘右键 → 退出，或 `Ctrl+Alt+Q`。
- **不要点「一键全部执行」**：它会结束课堂进程并卸载驱动，属于不可逆清扫。

## 3. 更新版本

直接编译覆盖 `bin\bypass.exe`：

1. **先退出托盘里的实例**：托盘右键 → 退出，或 `Ctrl+Alt+Q`；
2. 运行 `build\build_bypass.bat`（默认输出就是 `..\bin\bypass.exe`）；
   或在根目录执行 `make.bat bypass`（等价，脚本会临时加好工具链 PATH，
   见根目录 `README.md` 第 4 节）。

> 运行中的 exe 会被系统锁住，不退出的话链接会报 `Permission denied`。
> 脚本里已经写了这句提示。

如果换的是 `bypass_hook32.dll`：**必须重启课堂软件**。
同路径 DLL 重复注入不会重跑 `DllMain`，日志首行 `build=` 不会变。

确认是否真的换了：看 `bin\bypass_hook.log` 第一行：

```
build=Oct 22 2026 23:36:28
```

## 4. 配置与安全阀（都在 `bin\`）

持久配置在 `bin\bypass_config.ini`，主程序会自动生成；手工改完保存，1 秒内生效：

| 键 | 作用 |
|---|---|
| `window_mode` | `1`（默认）= 窗口模式；`0` = 关闭 |
| `title_autohide` | `1`（默认）= 最大化后自动隐藏标题栏；`0` = 关闭 |
| `minimize_mode` | `taskbar`（默认，真最小化）/ `tray`（隐藏收起） |
| `small` | 小窗尺寸：空/`0` = 默认；`0.35` = 屏宽比例；`900x500` = 固定外框 |

安全阀单独保留文件：

| 文件 | 作用 |
|---|---|
| `bypass_hook.off` | 放行：已注入的 DLL 停止干预窗口（不用重启渲染器） |

> 退出程序**不会**写 `.off`；只有明确点「恢复全屏广播（放行）」或关掉「持续保持小窗」才写。
> 「强制小窗 / 恢复被收起的窗口」由程序内部通知，不需要再建文件。

## 5. 故障对照

| 现象 | 原因 | 处理 |
|---|---|---|
| 点按钮提示"找不到 DLL" | Defender 把 DLL 删了 | 加排除项，重新解压 |
| 注入了但没效果 | 同路径旧 DLL 已在进程里 | 重启课堂软件 |
| 日志里没有 `build=` 新时间 | 同上 | 同上 |
| 小窗还是被拉回 | 还在 `--持续保持小窗` 且窗口被别的进程改 | 看 `bin\bypass_hook.log` 里 `keep user geometry` 的来源 PID |
| 最大化后没有标题栏/按钮 | 自动隐藏生效（默认行为） | 鼠标移到窗口最上沿；或在 `bypass_config.ini` 设 `title_autohide=0` |
| 切到黑桌面回不来 | 桌面守护被关了 | 检查 `bypass_config.ini` 的 `window_mode` 和主程序设置 |

## 6. 边界

- 两个工具都只用于**自己拥有/被授权管理**的机器与网络。
- 接管教师连接会让真教师看到该学生掉线，这不是"隐身"操作。
