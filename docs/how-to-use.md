# 使用手册（classroom-window-helper v2.0）

> 本工具只解决本机全屏广播问题：把广播变成可拖动小窗、解锁键盘。

> 目录结构、编译方法和文档索引见 [`../README.md`](../README.md)。

---

## 1. 部署 `classroom-window-helper`

1. 把整个仓库文件夹放到**本机磁盘**（例如 `C:\classroom-window-helper\`）。
   > ⚠ 不要放在 VMware 共享目录。HGFS 不支持 image section 映射，`LoadLibraryW` 会失败。
2. 给这个文件夹加 **Defender 排除项**（DLL 含 IAT patch / 注入代码，容易被判 HackTool 直接删）。
3. 双击 `bin\bypass.exe`（**不用**先右键"以管理员身份运行"，也**没有**确认弹窗）：
   - 直接开始自动提权（`bin\lpe\`，10~30 秒，期间有进度小窗）；
   - 失败自动弹 UAC；UAC 也失败（取消 / 被策略拦）才提示你右键 → 以管理员身份运行；
   - 已经在运行时双击不会重复启动，只会把已有窗口叫到前台；
- 需要跳过 LPE：临时把 `bin\lpe\` 改名（或删掉 `trigger.ps1`），启动器检测不到 payload 会直接走 UAC；或命令行加 `--elevate=uac`。
4. 托盘出现图标，主窗口启动时直接显示；点 `×` 或最小化后才收进托盘，
   **左键单击托盘图标**（或 `Ctrl+Alt+H`、或再双击一次 `bin\bypass.exe`）就重新打开。
   > 窗口开着时任务栏上也有按钮；图标如果被 Windows 折叠进任务栏的 `^` 里，
   > 窗口最小化后也能从 `^` 里找到它，不会"消失"。

**三个运行文件都在 `bin\`，必须同目录**：`bypass.exe`、`bypass_hook32.dll`、`inject32.exe`。
DLL 会按自己的位置去找开关文件和写日志。

## 2. 日常怎么用

> **默认就是「持续保持小窗」开启状态**（不用再点按钮）：程序启动后会自动注入 DLL、
> 装窗口事件钩子，广播一来就是小窗。
>
> 想**正常看全屏广播**：把「持续保持小窗」关掉（按钮/`Ctrl+Alt+T`/托盘）。
> 关闭时会写 `bin\bypass_hook.off` 放行，**桌面看门狗同时停止工作**，不会干扰教师端的全屏。
>
> 桌面看门狗只在小窗模式开启时生效：被切到 `NetTeachingDesktop` 会 1 秒内切回 `Default`；
> 黑屏锁屏（`MCLOCK Desktop`）则连带自动解锁键盘（`0xB2008`）。
>
> **课堂软件在 bypass 之后才启动也没关系**：程序每 400ms 看一眼进程表，
> `Student.exe` 一出现就注入；它拉起 `MultiClient.exe` 时会被"挂起注入"，
> 赶在 `SwitchDesktop` 之前把钩子装好。

### 2.1 上课前

运行 `bin\bypass.exe` 就行——**「持续保持小窗」已经默认开启**，自动注入、自动监视。

只有当前已经被锁的时候才需要补点：

| 按钮 | 什么时候点 |
|---|---|
| **解锁键盘** | 键盘被锁（打字没反应） |
| **屏蔽屏幕监控** | 老师端"屏幕监控/录屏"时不想让他看到实时桌面：开了之后老师端只能看到**一张定格画面**（第一次抓屏那一刻），之后完全不动；再点一次关闭。日志里会有 `[Screen] guard ON`（DLL 已注入）或提示注入失败。详细原理与边界见 `docs\design.md` 2.6。两个注意事项：**①** 界面会自动收进托盘——更新后的 Windows 把「对抓屏排除的窗口」渲染成黑色（防泄露加固），界面开着时武装会把工具窗口的黑洞永久烤进定格帧；**②** 想让定格帧有内容，在广播画面全屏显示时开（收托盘不影响广播窗口）。 |
| **屏蔽控制端重启/关机**（勾选框） | 老师端菜单里的「远程关机 / 远程重启」不要生效时勾上：本机不会关机/重启，日志里留 `[Guard] blocked ExitWindowsEx flags=0x6 (restart)` / `0x1 (shutdown)` 或 `[Guard] blocked CreateProcessW (shutdown -s -t 1)`。面板收进托盘时右键托盘图标，菜单里也有同一个开关。只吞课堂命令，**你自己从开始菜单关机不受影响**。详见 `docs\design.md` 2.7 |
| **检查当前状态** | 只读诊断。其中的 `Guard Status` 段会列出两个守卫的开关，以及每个课堂进程里 `bypass_hook32.dll` 的构建时间；显示 `OLD` 说明那个进程还在用旧 DLL，要**重启课堂客户端**（只重启 `bypass.exe` 不会替换已注入的 DLL）。末尾的 `Shared Log` 段是**增量**的：第一次点显示整份共享日志（提权链路、payload 的 `[elevate]` 行、DLL 的行都在文件里，GUI 框平时看不到），之后再点只补上次之后的新增行；文件被新一轮启动截断时自动从头显示。 |

> 想**正常看全屏广播**：关掉「持续保持小窗」（`Ctrl+Alt+T` 或按钮）。
> 关闭后会写 `bin\bypass_hook.off` 放行，看门狗也同时停止，完全不干扰教师端。

### 2.2 广播来了之后

默认**窗口模式是开的**（不需要你去开）：

- 渲染器不会切到 `NetTeachingDesktop`（不会整屏黑）；
- `fullscreen` 参数被改成 0 → 广播窗口本身是 **3/4 屏的普通窗口**（有标题栏、可缩放）。

窗口大小**你自己拖大/最大化，工具不会再拉回去**——这是刻意做的。拖到接近满屏
也算你的选择（松手时记录的矩形就是"还原"目标），渲染器随后发它缓存的小尺寸
也会被挡掉；只有"模拟最大化"状态下的拖动会保留原来的小窗还原点。

> **键盘解锁**：自动解锁已移除（实测不可靠）。键盘被锁时**快捷键按不出来**，
> 用鼠标点主界面「解锁键盘」；如果鼠标也被冻结，先按 `Ctrl+Alt+E` 应急点击一次。
>
> **最大化后标题栏自动隐藏**：把广播小窗最大化后，标题栏（最小化/最大化/关闭）
> 会在约 1.2 秒后自动收起，画面看起来像全屏；**鼠标移到窗口最上沿**
> （6 像素内）控制栏立刻回来，移开一会儿又自动隐藏。
> 不想要这个行为：在 `bin\bypass_config.ini` 里设 `title_autohide=0`
> （删掉即恢复，见第 4 节）。
>
> **最小化怎么收**：主界面有勾选框「广播窗最小化到任务栏」（默认勾选）。
> 勾选 = 真最小化，任务栏出现按钮，点任务栏（或缩略图、右键「还原」）恢复；
> 取消 = 收起（隐藏、不占任务栏），恢复方式：按 `Ctrl+Alt+T` 关掉「持续保持小窗」
> 再打开（写入 `bypass_hook.off` 放行后渲染器下一次 `ShowWindow` 会把窗口带回来），
> 或者直接重启课堂软件。
> 为了不让渲染器把最小化顶回来，DLL 除了内联 hook `user32!ShowWindow/ShowWindowAsync`
> （日志 `inline hook installed`），还会在最小化期间：
> ① 打 `BypassTaskbarMin` 锁，拦掉应用发来的 `SC_RESTORE` **和 `SC_MAXIMIZE`**（`DefWindowProc`
> 处理它们时都**不经过** `ShowWindow` 导出，钩子看不到）；
> ② 万一还有别的路径把窗口顶出来，在 `WM_WINDOWPOSCHANGED` 里立刻压回去
> （日志 `re-minimize ...`）。
> 判断"是不是用户点的任务栏"看光标是否在任务栏/缩略图/系统菜单上且有输入，
> 窗口是否收到 `WA_CLICKACTIVE`，以及**窗口菜单是否刚被打开/关闭**（任务栏右键、
> 标题栏图标、Alt+空格）。所以任务栏右键菜单里的「还原 / 最大化」也能用。

### 2.3 快捷键（鼠标被冻结时也能用）

| 快捷键 | 动作 |
|---|---|
| `Ctrl+Alt+H` | 显示/隐藏主窗口 |
| `Ctrl+Alt+T` | 持续保持小窗（开/关） |
| `Ctrl+Alt+D` | 立即切回桌面（被切到教学桌面时） |
| `Ctrl+Alt+E` | 应急点击（鼠标被冻结时） |
| `Ctrl+Alt+M` | 屏蔽屏幕监控（开/关）——**备用入口**，主入口是主界面按钮 |
| `Ctrl+Alt+Q` | 退出 |
| `Ctrl+Alt+X` | 应急放行 |

按钮上悬停会显示对应快捷键。

### 2.4 收尾

- 平时：直接关窗口（或最小化）→ 收进托盘，继续后台工作。
- 完全退出：托盘右键 → 退出，或 `Ctrl+Alt+Q`。

## 3. 更新版本

直接编译覆盖 `bin\bypass.exe`：

1. **先退出托盘里的实例**：托盘右键 → 退出，或 `Ctrl+Alt+Q`；
2. 运行 `build\build_bypass.bat`（默认输出就是 `..\bin\bypass.exe`）；
   或在根目录执行 `make.bat bypass`（等价，脚本会临时加好工具链 PATH，
   见根目录 `README.md` 第 4 节）。

> 运行中的 exe 会被系统锁住，不退出的话链接会报 `Permission denied`。
> 脚本里已经写了这句提示。

如果换的是 `bypass_hook32.dll`：**必须重启课堂软件**。
同路径 DLL 重复注入不会重跑 `DllMain`，日志首行 `build=` 不会变。

确认是否真的换了：看 `bin\bypass_hook.log` 第一行：

```
build=Oct 22 2026 23:36:28
```

## 4. 配置与安全阀（都在 `bin\`）

持久配置在 `bin\bypass_config.ini`，主程序会自动生成；手工改完保存，1 秒内生效：

| 键 | 作用 |
|---|---|
| `window_mode` | `1`（默认）= 窗口模式；`0` = 关闭 |
| `title_autohide` | `1`（默认）= 最大化后自动隐藏标题栏；`0` = 关闭 |
| `minimize_mode` | `taskbar`（默认，真最小化）/ `tray`（隐藏收起） |
| `small` | 小窗尺寸：空/`0` = 默认；`0.35` = 屏宽比例；`900x500` = 固定外框 |

虚拟桌面固定在 `bin\bypass_vd.ini`（DLL 生成，改完 5 秒内生效）：

| 键 | 作用 |
|---|---|
| `enabled` | `1`（默认）= 把广播窗钉在指定虚拟桌面；`0` = 老行为（窗口跟着当前桌面走） |
| `desktop` | 虚拟桌面序号，`0`（默认）= 第一个（一号桌面） |
| `guid` | 可选，直接写 `{GUID}`，优先于 `desktop=` |
| `pinned` | 工具自己写：当前生效的桌面；清空 = 下次按 `desktop=` 重新解析 |

安全阀单独保留文件：

| 文件 | 作用 |
|---|---|
| `bypass_hook.off` | 放行：已注入的 DLL 停止干预窗口（不用重启渲染器） |

> 退出程序**不会**写 `.off`；只有明确点「恢复全屏广播（放行）」或关掉「持续保持小窗」才写。
> 「强制小窗 / 恢复被收起的窗口」由程序内部通知，不需要再建文件。

## 5. 故障对照

| 现象 | 原因 | 处理 |
|---|---|---|
| 点按钮提示"找不到 DLL" | Defender 把 DLL 删了 | 加排除项，重新解压 |
| 双击后长时间没反应 | 正在跑自动提权（会显示进度小窗，`bin\bypass_hook.log` 里能看到进度），最多 60 秒 | 等它走完；想立刻放弃就点小窗上的「跳过，直接弹 UAC」 |
| 双击后没弹任何东西就退出了 | 工具已经在运行（托盘里有图标）——防重复设计，不会白跑一遍提权/UAC | 找托盘图标；找不到按 `Ctrl+Alt+H` |
| 最小化/关闭后托盘里找不到图标 | 图标可能在托盘的「显示隐藏的图标」（`^`）折叠区；或本机 shell 的托盘没建出来 | 先点任务栏的 `^` 看看；再从折叠区把图标拖到任务栏（Explorer 会按 exe 路径记住）。窗口可见时任务栏上有按钮，最小化后也可以先点 `^`。仍然没有就看 `bin\bypass_hook.log` 里的 `[Tray]` 行：`NIM_ADD failed err=...` 是创建失败（程序会重试 20 次，并**拒绝隐藏窗口**，不会让你找不到窗口）；`[Tray] env ... tray_hwnd=0000000000000000` 说明进程不在用户桌面/会话上 |
| 提示"禁止运行脚本" / 自动提权没反应 | 手动跑 `.ps1` 才会撞执行策略；工具把脚本落到 `%LOCALAPPDATA%\ClassroomBypass-LPE\` 后用 `-Command` 执行，不受策略限制 | 手动测试用 `powershell -ExecutionPolicy Bypass -File ... -TargetCommand ...`；集成路径看 `bin\bypass_hook.log` 里 `[elevate]` 进度行和 payload 输出；LPE 退回 UAC 先看 `selftest:` / `lpe: payload` 两行 |
| 自动提权失败 | 系统已打补丁（2026-07 后）、Defender 拦了载荷、或非 Win11 25H2 | 看 `bin\bypass_hook.log` 的 `[elevate]` 行和 payload 输出；直接在 UAC 里点"是"，或 点 UAC 提示的「是」即可 |
| 想完全跳过自动提权 | 可选 | 临时删掉 `bin\lpe\trigger.ps1`（启动器检测不到 payload 会直接走 UAC），或命令行加 `--elevate=uac` |
| 注入了但没效果 | 同路径旧 DLL 已在进程里 | 重启课堂软件 |
| 日志里没有 `build=` 新时间 | 同上 | 同上 |
| 小窗还是被拉回 | 还在 `--持续保持小窗` 且窗口被别的进程改 | 看 `bin\bypass_hook.log` 里 `keep user geometry` 的来源 PID |
| 最大化后没有标题栏/按钮 | 自动隐藏生效（默认行为） | 鼠标移到窗口最上沿；或在 `bypass_config.ini` 设 `title_autohide=0` |
| 切到黑桌面回不来 | 桌面守护被关了 | 检查 `bypass_config.ini` 的 `window_mode` 和主程序设置 |
| 切到二号桌面后再广播，窗口又跑到二号桌面 | 钉桌面被关了 / 渲染器在 `NetTeachingDesktop` 上 | 看 `bin\bypass_vd.ini` 的 `enabled`，以及日志里有没有 `vd: pinning disabled` |
| 重新广播时又被拽回被钉住的那块桌面 | 激活抑制没生效（旧 DLL / 目标桌面判断失败） | 每个被注入进程启动时应有一行 `vd: pinning on ... targetIsCurrent=0 (activation suppressed)`；随后是 `vd: forced SWP_NOACTIVATE` / `vd: ShowWindow(5) -> SW_SHOWNOACTIVATE`（同一条最多 15 秒打一次）。若看到的是 `(activation allowed)` 而人又在别的桌面，说明判定失败，把这一行发给维护者 |
| `bypass_hook.log` 里混着上一轮的记录 | 主程序不是最新版（旧版不截断日志） | 每次启动主程序都会清空；确认 `bin\bypass.exe` 是最近一次构建的产物 |
| 想让窗口跟着当前桌面走 | —— | `bin\bypass_vd.ini` 设 `enabled=0`（不用重启课堂软件） |
| 窗口模式广播的小窗一直压在我窗口上面 | 本版会自动摘掉它出生时就带的置顶。`bin\bypass_hook.log` 里应有 `untopmost hwnd=... (window-mode broadcast)`；一条都没有说明 DLL 没进渲染进程，按上面「窗口不动 / 没反应」那行查 |

## 6. 边界

- 两个工具都只用于**自己拥有/被授权管理**的机器与网络。
- 接管教师连接会让真教师看到该学生掉线，这不是"隐身"操作。
